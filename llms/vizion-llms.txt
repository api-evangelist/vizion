## API Reference
- [Introduction](https://docs.vizionapi.com/reference/introduction.md): Get real-time container tracking data via API
- [Authentication](https://docs.vizionapi.com/reference/authentication.md)
- [Status codes](https://docs.vizionapi.com/reference/status-codes.md): Vizion API's HTTP response codes
- [Carriers](https://docs.vizionapi.com/reference/carriers.md)
- [IP addresses](https://docs.vizionapi.com/reference/ips.md): Ensure your integration securely communicates with Vizion.
- [Webhooks](https://docs.vizionapi.com/reference/webhooks.md): Automatically receive tracking updates as soon as they are available.
- [Webhook Events](https://docs.vizionapi.com/reference/webhooks-events.md): Subscribing to notifications and alerts through webhooks.
- [Tagging](https://docs.vizionapi.com/reference/tagging.md): Organize and categorize references with tags.
- [Reference Events](https://docs.vizionapi.com/reference/reference-events.md): Visibility into the lifecycle of a reference.
- [Pagination](https://docs.vizionapi.com/reference/pagination.md)
- [Create a new reference](https://docs.vizionapi.com/reference/reference_create.md): Create a reference to begin tracking per the [configured cadence](doc:configurable-tracking-frequency).  Related docs: - [Quick start](doc:quick-start)
- [List active references](https://docs.vizionapi.com/reference/reference_list.md): List all `active` references, sorted by creation date (newest first).
- [Get reference](https://docs.vizionapi.com/reference/reference_get.md): Returns a reference for a given id.
- [Unsubscribe a reference](https://docs.vizionapi.com/reference/reference_deactivate.md): Unsubscribe a reference to stop tracking.  Once unsubscribed, a reference is considered "deactivated" and the API will no longer create updates for the given reference.  - If present, all reference children will be unsubscribed.  - If a `callback_url` was provided, webhook updates will no longer be sent.
- [List reference updates](https://docs.vizionapi.com/reference/reference_updates_list.md): Returns updates for a given reference id.  Related docs: - [Quick start](doc:quick-start) - [Check reference status](doc:reference-status) - [Common issues and steps to troubleshoot](doc:common-issues)
- [List container trace](https://docs.vizionapi.com/reference/reference_trace_list.md): > ⚠️ Pro Tier Only For access, please [contact support](https://share.hsforms.com/1B6wNyBBSR6uMotj--8Z_0Q56czk).  Returns an array of vessel movements for a given reference id.  Vessel movements are identified using the latest update.
- [List reference lifecycle events](https://docs.vizionapi.com/reference/reference_events_list.md): Returns the lifecycle event log for a given reference id.  The lifecycle log is an append-only record of significant events for a reference — creation, deactivation, reactivation, extraction attempts, reference updates, and estimated event changes. Events are retained for 18 months.  Pagination is cursor-based: pass the returned `next_cursor` as the `cursor` query parameter to fetch the next page. When there are no further results, `next_cursor` is `null`.  Related docs: - [Reference events](doc:reference-events)
- [List last known positions](https://docs.vizionapi.com/reference/reference_last_known_positions_list.md): > ⚠️ Pro Tier Only For access, please [contact support](https://share.hsforms.com/1B6wNyBBSR6uMotj--8Z_0Q56czk).  Returns the last known position for each container reference in your organization. Positions are derived from the latest carrier milestone with a transport mode, and — when the container is on a vessel — enriched with live AIS coordinates.  Parent references (bill-of-lading-only or booking-only) are excluded; only references with a `container_id` are returned.
- [List carriers](https://docs.vizionapi.com/reference/carrier_list.md): Get all carriers. Returns all supported carriers, and the corresponding `carrier_code` and `scac` (**deprecated**) values.
- [List point-to-point transit offerings](https://docs.vizionapi.com/reference/schedules_transit_offering_list.md): List scheduled sailings between two ports, each broken into its individual legs.  Requires the point-to-point schedules capability: without it the request is rejected with `401`. Contact support@vizionapi.com to have it enabled.
- [Create a tag](https://docs.vizionapi.com/reference/tag_create.md): Create a new tag.
- [List tags](https://docs.vizionapi.com/reference/tag_list.md): List all tags.
- [Get tag](https://docs.vizionapi.com/reference/tag_get.md): Returns a tag for a given id.
- [Update tag](https://docs.vizionapi.com/reference/tag_update.md): Update a tag's name.
- [Delete tag](https://docs.vizionapi.com/reference/tag_delete.md): Delete a tag. This removes the tag from all associated references.
- [List references for a tag](https://docs.vizionapi.com/reference/tag_references_list.md): Returns all references associated with a given tag.
- [Add tags to a reference](https://docs.vizionapi.com/reference/reference_tags_add.md): Associate one or more tags with a reference.
- [Remove tag from a reference](https://docs.vizionapi.com/reference/reference_tag_remove.md): Remove the association between a tag and a reference.
- [Test callback integration](https://docs.vizionapi.com/reference/webhook_trigger_test.md): Trigger a test Status Update to the specified `callback_url`.   Related docs: - [Webhooks](ref:webhooks) - [HMAC validation](ref:authentication#verifying-a-vizion-hmac-signature) - [Custom Webhook authentication](doc:webhook-security#custom-authentication) - [HTTP status codes](ref:status-codes)
